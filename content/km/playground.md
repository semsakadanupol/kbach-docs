## ផ្នែកនីមួយៗ {#how-its-laid-out}

- **របារខាងលើ** សម្រាប់ project ទាំងមូល៖ **ឧទាហរណ៍** ដែលអ្នកកំពុងប្រើ (មានចំណុចតូចបើអ្នកបានកែ), ប៊ូតុង **Run** ជាមួយកុងតាក់ **Auto**, ការរៀបចំផ្ទាំង, ពេញអេក្រង់, **⋯** និង **Share**។
- **Editor** មានឯកសាររបស់អ្នក គឺ `index.html`, script និង `kbach.config.js` បន្ទាប់មកមានឯកសារពីរទៀតដែល Kbach សរសេរចេញពីឯកសារទាំងនោះ (អានបានតែប៉ុណ្ណោះ)៖ `kbach.css` ជា CSS សម្រាប់ class របស់អ្នក និង `native-styles.js` ជា style object ដែល `@kbach/react-native` ផ្តល់ឱ្យ class ដដែលនៅលើទូរសព្ទ។ Class ណាដែលគ្មានប្រសិទ្ធភាពនៅលើទូរសព្ទ មានសម្គាល់ថា **web only**។ របារស្ថានភាពខាងក្រោមមាន **Format**, ចំនួនបញ្ហា និង **Fix all** ពេលមាន class របស់ Tailwind CSS ដែលត្រូវប្តូរឈ្មោះ។
- **ផ្ទាំងមើល** សម្រាប់មើលទំព័រ៖ **Preview** ឬ **Console**, **Inspect**, mode ភ្លឺ ឬងងឹត និងទំហំឧបករណ៍។

រាល់ពេលបើក playground វាចាប់ផ្តើមពី **Landing page**។ កូដដែលអ្នកកែលើកមុនមិនបាត់ទេ៖ ចុច **Restore my last code** (នៅរបារស្ថានភាព និងក្នុងម៉ឺនុយ **⋯**) ដើម្បីយកវាមកវិញ។

## សាកលេងអ្វីខ្លះ {#things-to-try}

- ជ្រើស **Navbar** ពីឧទាហរណ៍ រួចប្តូរទៅ **Phone**៖ ពេលអេក្រង់តូចជាង `md` តំណភ្ជាប់ត្រូវបត់ចូលក្នុងម៉ឺនុយ ហើយប៊ូតុងម៉ឺនុយបើកវា។ បង្វិលទូរស័ព្ទជាផ្តេក៖ ទទឹង 844px ធំជាង `md` ដូច្នេះតំណភ្ជាប់បង្ហាញវិញ។
- បើក **Color explorer** ហើយចុចលើពណ៌ណាមួយ។ Script របស់វាផ្គុំឈ្មោះ class ដូចជា `bg-rose-9` ពេលកំពុងរត់ ហើយ playground បង្កើត CSS ភ្លាមពេល class លេចឡើង ដូច្នេះមិនចាំបាច់សរសេរ class ពេញឈ្មោះនៅកន្លែងណាទេ។
- ប្តូរទៅផ្ទាំង **script**។ វាជា JavaScript ឬ TypeScript (កុងតាក់ **JS / TS**)៖ type ត្រូវដកចេញមុនពេលរត់។ ក្នុង `classList.add('…')` ឬ `className = '…'` editor ណែនាំ class របស់ Kbach ហើយគូសបន្ទាត់ក្រោម class ដែលមិនស្គាល់ ដូចក្នុង HTML ដែរ។
- `console.log()` បង្ហាញក្នុងផ្ទាំង **Console**។ Error ក៏បង្ហាញពណ៌ក្រហមត្រង់បន្ទាត់របស់វាក្នុង script ដែរ។ Loop ដែលរត់មិនចេះចប់ ត្រូវបញ្ឈប់ក្រោយ 2 វិនាទី ដើម្បីកុំឱ្យទំព័រគាំង។
- ចុច **Inspect** (រូបព្រួញក្នុងប្រអប់) រួចដាក់ mouse លើផ្ទាំងមើល៖ element នីមួយៗបង្ហាញ margin, padding និងទំហំ។ ចុចលើ element ដើម្បីមើល class ជាមួយ CSS របស់វា box model និង style ដែលគណនារួច។ បិទ class ណាមួយដើម្បីមើលថាវាធ្វើអ្វី បន្ថែម class ឬលោតទៅ tag របស់វាដោយ **Code**។ ពេលកំពុង inspect, cursor ក្នុង HTML បំភ្លឺ element ដែលវានៅក្នុង។
- វាយ `ul>li*3` រួចចុច **Tab**៖ Emmet សរសេរ HTML ឱ្យ។ **Shift+Alt+F** រៀប format ឯកសារ ហើយតម្រៀប class គ្រប់បញ្ជី (layout មុន បន្ទាប់មកប្រអប់ អក្សរ រួច effect)។ ប៊ូតុងរូបក្តារចុចនៅរបារស្ថានភាព បង្ហាញ shortcut ទាំងអស់។
- **Console** មានកន្លែងវាយ៖ វាយ JavaScript ហើយចុច Enter ដើម្បីរត់វាក្នុងទំព័រ។ ចុចតំណ `script.js:12` របស់ error ដើម្បីលោតទៅបន្ទាត់នោះ។
- ប៊ូតុងរៀបចំផ្ទាំងនៅខាងលើ ដាក់ផ្ទាំងមើល **ពីក្រោម** ឬ **ក្បែរ** កូដ ដើម្បីឃើញទាំងពីរពេលវាយ ហើយអូសរបារនៅចន្លោះដើម្បីប្តូរទំហំ។ ឬប្តូរទៅ **ពេញអេក្រង់**។ ពេលរត់ម្តងទៀត ផ្ទាំងមើលនៅតែនៅត្រង់កន្លែងដែលអ្នក scroll ដល់។
- ចុចប៊ូតុងរូបព្រះច័ន្ទ ដើម្បីប្តូរផ្ទាំងមើលទៅងងឹត៖ class `dark:` ទាំងអស់ប្តូរតាម។
- បិទភ្ជាប់កូដ Tailwind CSS ដែលមានកម្រិតពណ៌ដូចជា `bg-blue-500`។ Editor គូសបន្ទាត់ក្រោមម្តងមួយ ហើយប្រាប់ class របស់ Kbach គឺ `bg-blue-6`។ ចុច **Fix all** នៅរបារស្ថានភាព ដើម្បីប្តូរទាំងអស់ក្នុងពេលតែមួយ។
- បិទ **Auto** ពេល script ធ្ងន់៖ ការកែប្រែនឹងរង់ចាំរហូតអ្នកចុច **Run** (ឬ Ctrl+Enter) ហើយប៊ូតុង Run មានចំណុចតូចបង្ហាញថាមានការកែប្រែកំពុងរង់ចាំ។
- ម៉ឺនុយ **⋯** បើកទំព័ររបស់អ្នកក្នុង tab ថ្មី ទាញយកជាឯកសារ HTML តែមួយ (មានទាំង CSS និង script យកទៅប្រើបានគ្រប់កន្លែង) និងកំណត់ឧទាហរណ៍ដែលអ្នកកែឡើងវិញ។
- **Share** ចម្លងតំណដែលមាន HTML និង script របស់អ្នក។ អ្នកណាបើកតំណនោះ នឹងឃើញទំព័រដូចគ្នា។

Script រត់ក្នុង sandbox៖ វាកែផ្ទាំងមើលបាន តែមិនអាចចូលដល់ទំព័រនេះ storage ឬ cookie របស់វាបានទេ។
